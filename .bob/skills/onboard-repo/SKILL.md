---

Use this skill when a new developer needs to understand the workspace and make a first safe change.

1. Read README.md, PROJECT.md, docs/RUNBOOK.md, package.json, and AGENTS.md if they exist.
2. Do not edit application code in this skill.
3. Write docs/BOB_ONBOARDING.md with:
   - A short architecture explanation
   - Setup checks: Node version, .env, install command, start command, health URL
   - Five starter tasks. Each task names one file and how to prove it worked.
   - Risks a new hire could hit in the first hour
4. Keep every claim tied to a file you opened.
5. If a document disagrees with the code, trust the code and say the document is stale.
